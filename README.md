## Experience

### Digital Intern, ERS Energy Sdn Bhd (Jun–Sep 2026)
Worked within a small, high-ownership Digital team on two production systems.

**Workflow automation (n8n + Google Sheets/Apps Script)**
Built and debugged a multi-branch webhook-driven pipeline that routes web form submissions into structured spreadsheet storage and downstream CRM sync logic. Diagnosed and fixed a set of production data-integrity issues, including:
- A silent Apps Script bug caused by a duplicate function definition overriding the intended logic at runtime
- A case-sensitivity bug that had quietly disabled a consent filter since launch
- Race conditions from concurrent trigger firings, resolved with proper locking
- Replaced fragile state tracking with a scoped, time-windowed deduplication model

**Fullstack rebuild — HR Management System (HRMS) (Next.js + TypeScript + Laravel)**
Built the frontend and backend for rebuilding a legacy spreadsheet-based time-tracking system into a mobile-first production web app: GPS-based location capture, photo proof-of-visit, role-based navigation (field staff vs. managers/HR), travel and training request modules, overtime review, and CI pipelines for a multi-branch git workflow.

**Approach:** I work iteratively. Ship a fix, verify against real data, get sign-off before touching shared production resources, and document the reasoning so the next person (or future me) doesn't have to rediscover it.

## Other Projects

### [ShelterLab](https://github.com/keirara04/ShelterLab), Campus Marketplace Platform
A full-stack peer-to-peer marketplace for Korean university students, supporting 10+ campuses with campus-exclusive feeds.

**What it does:**
- LabCred trust system, a transparent, tiered credibility score for marketplace users
- AI-assisted pricing suggestions using the Groq LLM API
- Admin dashboard with moderation tools and live usage statistics
- Rate limiting (Upstash Redis), JWT auth, and Postgres row-level security policies, built with PIPA compliance in mind
- Progressive Web App: offline support, installable, push notifications
- Email verification via Brevo SMTP

**Stack:** Next.js, React, Tailwind CSS, Supabase, Groq API, Upstash Redis
**Status:** 0.1.2-beta | [Live demo](https://shelterlab.shop)
